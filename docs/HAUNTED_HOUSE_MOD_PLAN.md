# お化け屋敷MOD 開発仕様

## 対象環境

- Minecraft 26.3
- Fabric
- Java 25
- リポジトリ: https://github.com/harukunpal-dotcom/urtabtt

## v1.0 の目標

### 1. お化け屋敷

同じ屋敷を、次の2通りでワールドに登場させる。

- **自然生成:** 探索中に見つかる構造物として生成する。森や暗いバイオームを優先候補とする。
- **招待状で生成:** 専用アイテム「お化け屋敷の招待状」を使用した位置に屋敷を配置する。

自然生成と招待状生成は、可能な限り同じ構造物データを共有し、見た目や部屋構成が食い違わないようにする。

### 2. 幽霊モンスター

- 敵対的なモンスターとして登録する。
- プレイヤーを発見すると追跡する。
- 屋敷の内部や暗い場所を主な出現場所にする。
- 専用の見た目、サウンド、ドロップ品を追加する。
- 体力・移動速度・攻撃力はゲーム内で調整できる値にまとめる。

### 3. 招待状アイテム

- アイテム名: お化け屋敷の招待状
- 使用時に屋敷を配置する。
- 配置可能な場所か確認し、失敗時にアイテムを消費しない。
- 成功時のみ、サバイバルでは1枚消費する。
- 既存建築を大きく壊さないよう、配置範囲を事前確認する。

## 実装順序

1. Fabric プロジェクト全体をリポジトリに揃え、26.3 向けのビルドを再現できる状態にする。
2. MOD ID、初期化クラス、アイテム登録の構成を確認する。
3. 幽霊エンティティを登録し、自然スポーンではなくテスト用スポーンから動作確認する。
4. 幽霊の追跡AI、モデル、テクスチャ、サウンドを追加する。
5. お化け屋敷の構造物データを作成し、テスト用配置を確認する。
6. 招待状アイテムから構造物を配置する処理を追加する。
7. バイオーム・頻度・配置条件を設定して自然生成を有効にする。
8. 新規ワールドと既存ワールドで動作確認し、配布用JARをビルドする。

## 互換性・品質ルール

- Minecraft 26.3 / Fabric / Java 25 を維持する。
- 実際のテンプレートに含まれるマッピング、Fabric API、Loom のバージョンを確認してからAPIを選ぶ。
- 既存ファイルを一度に大きく書き換えず、小さな変更ごとにビルドする。
- 自然生成は新しく生成されるチャンクが対象になることを説明する。
- ビルド成功とゲーム内動作確認を区別して報告する。
